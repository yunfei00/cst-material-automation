# 架构设计（v0.1.0）

目标：完全离线的 CST Studio Suite 2025 几何分析与材料赋值工具。

## 约束
- 真实 ASM/CST/材料文件和由其提取的几何、日志不得上传 GitHub。
- Creo View 11.0 仅为可选人工查看工具；不假设具备可编程导出接口。
- CST Python、COM、VBA 能力需要在公司 Windows 本地逐项验证。
- 材料属性和几何形状不能单独证明材料归属；无法确定时必须人工确认。

## 分层
1. UI：后续 PySide6 中文桌面端
2. 应用服务：任务编排、事务与恢复
3. 领域：Solid、Material、BoundingBox、验证状态
4. 算法：几何特征、相对关系、匹配、材料候选
5. 适配器：CST 2025 真实接口（待验证）
6. 本地持久化：后续 SQLite（不上传）

## P0 验收
本机真实 CST 验证：打开测试工程、枚举 Solid/材料、读取几何、修改副本材料、另存、关闭、回读。每项输出 PASS/FAIL/BLOCKED/NOT_RUN；未运行不得宣称通过。
