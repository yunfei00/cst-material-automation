# CST 2025 SP1 真实业务验证说明

## 已确认的环境事实

- CST Studio Suite 2025 SP1 已安装且可以通过 Python 调用。
- CST 安装目录的 Library 提供可通过 pip 安装的 Python Package。
- 用户已有可用的 `import cst` 调用代码。
- 早期在 uv 虚拟环境中检测 `cst`、`cst.interface`、`win32com`、`win32com.client` 均为 false，原因尚未独立复现；这**不影响已知的 CST 调用可用事实**。

## 已取消的无效验证

不再要求工程师执行环境模块探测、安装目录扫描、PowerShell 大段脚本或通用 pytest/Ruff 测试。相关诊断程序已从开发分支移除。

## 下一次真正需要验证什么

待开发者参考现有 CST Python 调用示例实现功能后，工程师只需在授权的 Windows CST 2025 SP1 环境中验证：

1. 能否读取指定测试工程中的 Solid / Component 列表。
2. 能否读取工程中的已有材料。
3. 能否在**测试副本**上给指定 Solid 赋予已有材料。
4. 能否另存、重新打开，并确认赋值保持正确且原始工程未改变。

目前以上真实业务能力均**尚未在本项目实现或验证**。无需提前运行任何命令。

## 数据安全

公司设计工程、材料库、几何提取结果、内部路径、截图和原始日志不得上传个人 GitHub。必要时只反馈脱敏后的结果和通用接口用法。
