# 手机电池纯几何识别（开发中）

## 目标
在 CST 导出的 STEP/B-rep Solid 中识别手机扁平长方体锂电池。禁止使用 Solid 名称、组件路径、材料、BOM、样本尺寸作为识别条件。圆孔、圆角、表面台阶是允许的局部结构，不是必要条件。

## 核心指标
- 实际体积 V；旋转包围盒尺寸 L>=W>=T，避免全局坐标朝向影响。
- 长宽比 L/W、平板度 T/sqrt(LW)、填充率 V/(LWT)。
- 沿最薄主轴的材料截线厚度分布，计算中位数、MAD 和无材料面积比例；避免仅测包围盒厚度。
- 主体平面覆盖率、连通性、孔洞和局部台阶。
- 大尺寸为同工程内的相对几何信息，不采用“体积前 N 名即电池”规则。

## 判定边界
体积大、填充率高、扁平、厚度一致仅能说明“电池形态”，不一定能唯一地区分 OLED、后盖、其他封装模组。证据不足时返回 UNKNOWN，不允许直接赋材。不可人为设置让特定样本通过的阈值或加权评分。

## 性能与界面
- 复用螺丝识别的 QProcess + ProcessPoolExecutor 工作流，Windows spawn-safe 顶层 worker，默认 8 进程，用户可配置。
- 复用 P5 索引、STEP 路径、SHA256 增量缓存、原子 JSON 报告、实时进度和取消。
- PySide6 左侧新增“电池”复选框，与其他结构过滤互斥；勾选即识别并过滤，取消勾选恢复列表。
- 仅显示明确匹配的结果；失败计数单独显示；不将 UNKNOWN 作为电池。

## 验收
1. 单 Solid 旋转/缩放不改变几何判定（涉及物理尺寸的工程相对条件除外）。
2. 有圆孔、圆角、台阶的厚实板状电池可识别。
3. 中框、后盖、OLED、PCB、屏蔽罩作为负例，记录误报。
4. 8 进程和单进程结果一致；中断恢复、缓存失效和 UI 取消有效。
5. 冻结螺丝 v29 行为不变，全部 CI 通过后才能合并。
