# 结构件识别算法文档

本目录统一记录 **CST Solid 的纯几何结构类别识别算法**。每个结构件独立一篇完整技术文档，便于后续开发、审查、回归和版本冻结。文档只记录可从真实几何获得的证据；不得将零件文件名、材料、样本尺寸或人工标签写成生产识别条件。

## 后续新增规则

每种结构件新增独立文件，例如 `shield-can.md`（屏蔽罩）、`spring-contact.md`（弹片）、`main-pcb.md`（主 PCB）；**这些只是预留文档名称，不表示算法已实现或验收**。

每篇文档统一包含：

1. **识别目标与排除范围**：正类定义、容易混淆的负类。
2. **输入输出**：STEP/B-rep 或其他真实输入、类别及证据字段。
3. **几何不变量**：与尺度、朝向、命名无关的可验证结构。
4. **算法步骤与流程图**：先廉价结构检查，后昂贵几何确认。
5. **关键代码映射**：模块、入口、函数及数据流。
6. **误报与漏报分析**：具体失败机制与防护，不能针对样本写特例。
7. **容差、性能与边界**：数值阈值的来源及失效场景。
8. **测试与验收**：合成回归、真实零件、全量扫描分别说明。
9. **版本历史与冻结基线**：提交、变更理由、回归状态。

## 维护原则

- **准确性优先**，不以“样本通过”代替类别级泛化。
- 纯重构不得悄悄修改几何判定阈值；识别行为变化单独提交。
- 无法确认时输出不确定/其他类别，不凭几何猜测材料。
- 文档和实现同步更新，注明尚未验证的能力。
