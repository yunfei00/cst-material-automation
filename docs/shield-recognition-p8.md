# P8 屏蔽罩识别：第一阶段（几何特征初筛）

当前实现只完成**不依赖样本库的屏蔽罩候选初筛**，不是最终屏蔽罩识别，更不能自动赋材料。

## 使用

在 Windows 本地运行：

```powershell
uv run --extra viewer python view_solids.py "D:\\CST\\Original.solid_export_diagnostic"
```

点击左侧 **筛选屏蔽罩候选**，按分数查看候选并逐个确认。无需重新导出 STEP；已有 `geometry_features.sqlite3` 即可完成初筛，文件夹搬迁不影响数据库读取。

## 当前规则

- 包围盒填充率 ≤ 0.4：35 分
- 次长尺寸 / 最短尺寸 ≥ 3：20 分
- 最长尺寸 / 最短尺寸 ≥ 5：10 分
- 表面积 / 体积 ≥ 0.5 mm⁻¹：15 分
- 平面面数 ≥ 6：20 分

合计 ≥ 55 分进入待人工复核列表。分数是**启发式规则分数，不是准确率或识别概率**。规则仅用于缩小待检查范围，可能遗漏真实屏蔽罩，也可能把支架、散热片等误判为候选。

## P8-B：精确 STEP 几何检查（初版）

左侧点击 **筛选屏蔽罩候选** 后，选中候选 Solid，再点击 **精细检查当前屏蔽罩**。程序只读取当前选中的 STEP，利用 OCP B-rep 分析最大平面、与其近似平行和垂直的平面面、面面积及包围盒填充率，右侧显示规则分数和逐条证据。

注意：**目前没有完成开口、连续围合和局部壁厚的可靠判定**，因此精细检查仍属于几何证据筛查，而不是屏蔽罩身份确认。矩形盒体、金属支架等可能误报；异形或曲面罩体可能漏报。缺少 STEP 时仅支持 P8-A 数据库初筛，无法运行 P8-B。真实 CST STEP 的验收必须在本地完成。

后续应针对真实屏蔽罩与反例实现壁厚测量、面邻接拓扑、开口方向及围合检测，再调整规则阈值。

## P8-B2：中心轴空腔探测

对主平面法向接近全局 X/Y/Z 轴的单体 Solid，在包围盒中心轴上选取 7 个相对位置，使用精确 B-rep 的 `classify_point` 判断材料内部、表面或外部。记录每个采样点及“轴向空腔可能”“端部开放可能”的可解释证据。若主平面非轴对齐或缺少包围盒坐标，则标记为不支持，不伪造结果。

**限制**：中心轴的 OUTSIDE 点可能属于实体外部、开槽或穿孔，不能证明真实空腔连通到外界，也不能证明侧壁连续围合或局部壁厚。P8-B2 只提高候选解释能力，后续需要多射线采样、邻接拓扑和真实反例验收。
