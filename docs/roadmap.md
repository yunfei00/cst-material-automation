# CST 材料自动化研发路线

## 输入约束（已确认）

- 只有**一个已经包含三维结构与材料定义的 CST 工程**（`.cst`）。
- 不导入 SAT / ACIS，不导入外部材料库，不新建空工程。
- Windows 已安装 CST Studio Suite 2025 SP1，Python `import cst` 已验证；不再重复环境探测。

## P1/P2（本分支已经提交代码，实机尚待验收）

- **P1 — `inventory`**：通过 CST Python `model3d.get_tree_items()` 读取结构树和材料名称，通过 VBA 查询 Solid 当前材料，输出本地中文 JSON 报告。原始 CST 工程保持不变。
- **P2 — `assign`**：根据工程师指定的 Solid→已有材料映射，打开工程副本，通过 VBA 修改材料，保存并重新打开核对。
- **现状**：代码与命令行已接入；无 CST 的 CI 单元测试覆盖流程；完整 CST 2025 Online Help 已提供 VBA_3D Solid/Material/Component 官方接口签名，P1 增加官方 VBA Solid 枚举与工程树交叉验证；**真实 CST 2025 SP1 运行行为尚待实机确认**。
- [P1/P2 运行与验证说明](p1-p2-verification.md) 提供完整命令和失败诊断。

## 后续阶段

1. **真实 CST 验收**：确认树路径、实体材料 VBA 查询、赋值、回读，在本地非生产测试工程上形成 PASS 证据。
2. **P3 — 结构特征分析**：抽取位置、尺寸及相关空间关系，建立可解释的候选规则。
3. **P4 — 材料匹配推荐**：根据工程中已有材料自动生成候选与证据，低置信度交给工程师确认。
4. **P5 — Windows 中文图形界面**：批量处理、运行结果、异常恢复、离线发布。

任何阶段都不得上传公司内部 CST 设计及材料信息到个人 GitHub。未经许可不合并 main。
