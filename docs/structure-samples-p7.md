# P7 结构样本库：批量确认与跨工程复用

P7 在 P5/P6 的离线特征库与三维查看器基础上工作。样本库保存在本机用户目录 `~/.cst_material_automation/structure_samples_v1.json`，可供同一台电脑上的其他工程复用。

## 操作

1. 使用 `uv run --extra viewer python view_solids.py "导出目录"` 打开已完成 P5 的目录。
2. 选中一个已知结构，设置左侧 **最低相似度**（初始 0.980），点击 **以当前 Solid 搜索相似**。
3. 点击候选，逐个查看三维结构；仅勾选**人工确认确实属于同一结构类别**的条目。
4. 在右侧 **真实零件类别** 输入例如 `SPRING_CONTACT`，点击左侧 **将勾选结果批量保存为结构样本**，阅读确认弹窗后保存。
5. 右侧 **管理已确认结构样本** 可以查看样本并选择删除错误记录。
6. 打开其他工程后，右侧 **结构相似样本** 会对当前选中的 Solid 展示最接近的已确认样本类别和相似度。

## 安全与验收

- 相似度不是准确率，0.980 是可调的检索门槛，不是自动确认门槛。
- 批量保存使用一次原子写入；已有样本 ID 冲突会拒绝整批，不会静默覆盖。
- 批量保存和删除仅修改本机 JSON 样本库；不会改 CST 工程、自动赋材料。
- P7 的跨工程复用是**候选推荐**，仍需要工程师确认。
- 验收建议：在原工程确认 3–10 个弹片样本，再打开另一工程查看相似候选，检查误报/漏报并记录结果。
